所有通知、课程、教师和地点均为演示内容，不包含真实个人信息。文件不会自动导入手机，也不会自动向QQ群发送消息。

为了准备收件箱，通知文件一次复制一条到“今日右上角＋→粘贴通知原文”，点击“保存并自动整理”（需配置AI密钥）。口头记忆也能整理这些内容，但确认后直接创建待办，不经过待确认收件箱。

若测试QQ接入，由本人选择合适的测试群，在关注成功后自行发送。不要把这些示例发送到无关的真实群中。
